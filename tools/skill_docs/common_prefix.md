# `common_prefix()`

> **Get common prefix of a string vector**

## Description

Get common prefix of a string vector

## Usage

```r
common_prefix(x)
```

## Arguments

| 参数 | 说明 |
|------|------|
| `x` | A string vector. |

## Value

A string that is the common prefix of the input vector.

## Examples

```r
common_prefix(c("Q1_a", "Q1_b", "Q1_c"))
```

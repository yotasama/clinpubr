# `add_lists()`

> **Adding lists element-wise**

## Description

Combine lists by adding element-wise.

## Usage

```r
add_lists(l1, l2)
```

## Arguments

| 参数 | 说明 |
|------|------|
| `l1, l2` | A pair of lists. |

## Value

A list.

## Examples

```r
l1 <- list(a = 1, b = 2)
l2 <- list(a = 3, b = 4, c = 5)
add_lists(l1, l2)
```
